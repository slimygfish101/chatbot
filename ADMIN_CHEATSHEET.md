# Text Blast: Admin Cheat Sheet

Text the group number like a normal text. **Anything that doesn't start with `#` goes to every boy.**

| You text | What happens |
|---|---|
| Any normal message | Starts going out within a minute, 15 boys a minute (100 boys ≈ 7 minutes). A minute or two later you get a summary like "Sent to 98 of 100. 2 failed." |
| `#add 2125551234 Moshe` | Adds Moshe and sends him the welcome text |
| `#remove 2125551234` | Takes that boy off the list |
| `#count` | Tells you how many boys are on the list |
| `#cancel` | Stops a message that's still going out (or one that's waiting its turn) |
| `#help` | Texts you this list |

**Three rules**

1. **Keep messages under 160 plain letters.** Then each boy gets 1 text. Longer messages, emoji, Hebrew letters or "curly" quotes cost 2–3 texts per boy. The summary tells you when that happens.
2. **Never text STOP (or END, QUIT, CANCEL) to the group number.** The phone company would then block the number from texting you back. Use `#cancel` to stop a message.
3. **Pictures aren't sent.** Only the words go out.

**Good to know**

- If you send a second message while one is still going out, it waits its turn and goes out right after. If that second one was a mistake, text `#cancel` right away.
- Boys can't reply to everyone. Their replies are ignored, except STOP (takes them off the list) and HELP.
- If you `#add` a boy who once texted STOP, he isn't texted. He joins the list as soon as he texts START to the group number himself.
- Spelling matters after the `#`, and put a space before the number. A wrong command is never sent to the boys; you'll get "Unknown command".
